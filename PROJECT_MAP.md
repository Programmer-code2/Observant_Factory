# PROJECT_MAP — Observant Factory

**Data Flow:**
- All CRUD → `dbProvider` → `AppDatabase` (drift) → SQLite
- Images captured → copied to `getApplicationDocumentsDirectory()` → path stored in DB
- Reports generated in-memory → saved to temp → shared via `printing` share sheet
- Cascade deletes: Place → SubPlaces → InspectionItems → image files
- Language: `localeProvider` (Notifier) → `stringsProvider` (derived AppStrings) → UI

## [LOCALIZATION]

- **Arabic (ar):** Default RTL, Cairo font, Arabic labels
- **English (en):** LTR, same Cairo font, English labels
- **Switching:** Settings → language toggle → `LocaleNotifier.toggle()`
- **Material components:** `GlobalMaterialLocalizations.delegate` (from flutter_localizations)
- **App strings:** `AppStrings` class in `core/l10n.dart`
- **Reports:** `isArabic` parameter passed to `ReportService`, `AppStrings(isArabic)` for headers
- **Observation types:** `ObservationType.arabicLabel` / `.englishLabel` (9 types)
- **Schema version:** v2 (added `observer_name` column via migration)
- **Image optional:** `imagePath` stores `''` when no photo taken; card shows placeholder

## [NUMBER_FORMATTING]

- All dates use `DateFormat(..., 'en')` to force Western/Arabic-Indic digits (0-9) in all locales
- Number display via Dart string interpolation (`$count`) already produces English digits
- PDF headers explicitly use `'en'` locale for digit formatting

## [STATE_MANAGEMENT_REFRESH]

- `refreshProvider` (`NotifierProvider<int>`) in `database.dart` acts as a global invalidation signal
- All data `FutureProvider`s watch `refreshProvider` and re-execute when triggered
- Every mutation (add/delete place, sub-place, inspection item) calls `triggerRefresh()`
- Cross-screen sync: Dashboard and Observations screen refresh instantly when data changes from any screen
